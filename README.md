# BMS-H5-Code
This repository is to store all the code that I'm currently making for the battery management system. This code is going to be uploaded onto the STM32H5 (NUCLEO-H533RE) for now for testing, and then it will be used on the actual BMS board once we have that into production.

**Start here:** [docs/GUIDE.md](docs/GUIDE.md), a step-by-step setup and test guide.
The code lives on the milestone branches `m0-toolchain` → `m4-bms-node` (the latest).
